3. 機能要件

3.1 画像認識機能

AIが判定する項目：

  • 現在のゲーム状態（戦闘、ボックス、メニューなど）

  • 卵アイコン（小・大）

  • ポケモンの種類判定

  • アイテム判定

  • プレイヤーの向き

  • ミニマップ位置

  • 地図情報

3.2 操作制御機能

  • SwitchReport を生成し、UART または USB HID Vendor で送信

  • 1ms周期の HID ポーリングに追従可能な速度で送信

3.3 GUI機能

  • 自動化シナリオの選択

  • AI判定結果の表示

  • コントローラー接続状態の表示
