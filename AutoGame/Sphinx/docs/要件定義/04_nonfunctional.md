# 4. 非機能要件

## 4.1 通信性能（UART）
- 115200bps（約11.5KB/s）
- 1バイト送信：約 87?s
- SwitchReport（8バイト）：約 700?s
- HIDポーリング：1ms周期 → UARTでも十分対応可能

## 4.2 AIモデル
使用予定のAI技術：

- YOLO（UI検出・ミニマップ検出）
- MobileNet（ポケモン種類判定）
- OCR（技名・アイテム名）
- OpenCV（ミニマップ位置特定）
- ONNX Runtime（高速化）

※AIに提案された構成のため、検証しながら採用可否を判断する。

## 4.3 画面解析性能
- キャプチャデバイスの遅延を考慮し、推論速度は 30?60fps を目標とする。
